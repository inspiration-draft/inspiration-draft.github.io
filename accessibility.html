Accessibility

InspirationDraft is designed to work with Apple's built-in accessibility technologies so that more people can capture, review, and expand ideas privately on iPhone.

Supported access features

  • Works with VoiceOver and standard iOS accessibility labels on major navigation and action controls.
  • Uses system text, buttons, sheets, and lists where possible so the app follows iOS accessibility behavior by default.
  • Supports Dynamic Type and larger text sizes through iOS text scaling.
  • Supports Dark Interface on iPhone.

Notes about AI-generated and imported content

Draft text, imported source material, AI-generated suggestions, and attached images may vary in structure and readability depending on the content you provide. We recommend reviewing AI output manually when using assistive technologies in a critical workflow.
